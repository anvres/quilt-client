## ⚔️ Бой

| Модуль | Описание |
|--------|----------|
| **Aura** | Продвинутая Kill Aura с несколькими режимами вращения |
| **AutoCrystal** | Автоматическая расстановка и подрыв кристаллов Эндера |
| **AutoTotem** | Автоматически перекладывает тотем в левую руку |
| **AutoSwap** | Автоматически переключается на лучшее оружие/инструмент |
| **AntiBot** | Фильтрует ботов из целей ауры |
| **ClickPearl** | Бросает жемчуг Эндера по клику |
| **HitBox** | Расширяет хитбоксы существ |
| **PacketCriticals** | Отправляет пакеты крита без прыжка |
| **Velocity** | Уменьшает или полностью убирает отдачу от ударов |

## 🛠️ Сборка

**Требования:** Java 21, Gradle

```bash
./gradlew build
```

Готовый jar будет в папке `build/libs/`.
