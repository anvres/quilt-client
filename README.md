## 🛠️ Building

**Requirements:** Java 21, Gradle

```bash
./gradlew build
```

Output jar will be in `build/libs/`.

---

## ⚙️ Stack

- **Minecraft** 1.21.4
- **Fabric Loader** 0.16.10
- **Fabric API** 0.119.3+1.21.4
- **Yarn Mappings** 1.21.4+build.8
